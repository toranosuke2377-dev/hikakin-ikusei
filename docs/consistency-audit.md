# 全章・分岐・正史の整合性監査

監査日: 2026-08-17

## 1. 完成状態と正本

本作は、画像・動画・音声素材を除き、全5章を最初から5種類の結末まで遊べるPCブラウザアプリとして実装されている。

設定や挙動が文書間で異なる場合は、次の順で現在の正本を判断する。

1. `src/game/types.ts` と `src/game/constants.ts` — 数値、章、保存形式
2. `src/data/chapter1.ts`〜`chapter5.ts`、`replayEvents.ts`、`endings.ts` — 実際に表示される物語と条件
3. `src/game/engine.ts` — 抽選、効果、章進行、結末判定
4. `docs/branch-map.md` — 全章を通した物語意図
5. `docs/game-design.md` — 壁打ちで確定した企画と制作過程

初期構想から分量を拡張し、現在は60個の基本進行スロットと条件付き追加場面で約1時間に整えている。伝説の一本も『音が止まるまで』として確定済みである。この監査と実装を完成版の基準とする。

## 3. 変えてはいけない主人公の核

開始時のヒカキンは、YouTubeを仕事にする発想こそ持っていないが、「絶対に何者かになってやる」という強い野心を最初から持つ。選択によってこの野心そのものが消えたり、最初から受け身の人物になったりはしない。

選択で変わるのは、何者になろうとするか、どんな手段を選ぶかである。

- ビートボックスの技術を極める職人
- 幅広い企画で皆を楽しませる王道の人気者
- 数字と流行を分析する戦略家
- 仲間との関係から企画を大きくする調整役
- 他人の魅力を発見する制作者
- 炎上を利用してでも注目を奪う人物
- 生活を守りながら機会を待つ人物

物語の視点は第三者。プレイヤーは本人として台詞を直接入力するのではなく、人生の節目で判断を与え、その結果としてヒカキンの人格と人生を見届ける。

## 4. 全5章の正史

### 第1章「無名のビートボクサー」

固定される事実:

- 1989年4月生まれ。2008年3月、高校卒業直後の18歳で新潟から東京へ上京
- 小学3年から高校までスキージャンプを続け、全国8位。大学の競技推薦ではなく東京就職を選ぶ
- 「ヒカキン」はスキーの先輩から付いた呼び名として、周回回想で由来を描く
- 親から渡された所持金は2万円
- 高校へ届いた二件の東京求人からスーパーを選び、食料入りの段ボールを持って上京。給料から家賃が引かれる社員寮へ入る
- 海外ビートボクサーの動画を見るためYouTubeを使い、「自分も投稿すれば見てもらえるのでは」と考える
- 中学生からビートボックスを独学し、音楽室、文化祭、ライブを経験。未熟な初期投稿は自分で削除する
- 安いマイクを使い、薄い壁を避けて社員寮の自室や浴室で何度も撮り直し、月1〜2本を投稿
- 早朝から品出し、倉庫整理、運搬、レジを行い、200円定食などで節約しながら睡眠を削る
- 研究熱心、継続力が高く、完璧主義寄り
- YouTubeパートナー申請を一度断られる
- 人偏堂『スーパーマッチ棒ブラザーズ』のBGMをビートボックスで再現する動画を作る
- 動画が大きく拡散し、YouTube側からパートナーのオファーが届く

最高の拡散では、24時間約20万アクセス、一週間約100万アクセス、国内月間アクセス1位、長期約1,000万再生へ到達する。大ヒットは固定された物語の核だが、国内、海外、技術、ゲームファン、論争など、伸び方と次章へ残る評価は変わる。
全拡散経路で、通勤途中の駅のホームにて伸びる数字を見て涙し、それでもスーパーへ出勤する。ヒット直後には辞めず、収益と貯金を確認して専業化する慎重さを第2章へつなぐ。

### 第2章「一千万回の向こう側」

一発の大ヒットを、継続して見てもらえるチャンネルへ変える章。ビートボックスに加え、商品紹介、ゲーム実況、料理、検証、雑談などYouTubeらしい企画を試す。スーパーを辞める時期と理由も分岐する。

海外クリエイターの生き方から「好きなことが仕事になる」可能性を知り、動画収益が会社員給与を継続して上回ることを退職の基準にする。上京からおよそ4年、引き継ぎと住居を整えたうえで専業へ移るのが責任ある正史ルートとなる。

人物関係の正史:

- まっすおはヒカキンより先に成功せず、ヒカキンが売れ始めるのと近い時期に伸びる
- ダンケは無名時代からの友人ではなく、本人も少し注目を集め始めた後に出会う
- ヒカキン、まっすお、ダンケは固定三人組ではない。各自が一人で企画、撮影、編集、投稿し、友人として時々遊び、相談し、コラボする
- サックスむらいは名前に反してサックスをほぼ吹かず、パズルゲーム『パズトラ』の実況、攻略、検証で人気になる
- 後発のはじめ課長はヒカキンを「親分」と呼んで慕い、友人でありライバルになる

### 第3章「YouTuber新時代」

個人制作から、大型企画、企業、編集協力、音楽、グループ投稿者が存在する産業へ移る章。ヒカキン自身が主人公であることを保ち、他の投稿者は制作体制、信用、企画方針、人間関係を選ばせる存在として登場する。

固定される軸:

- はじめ課長が大型企画で急成長し、日本一を争う将来が見え始める
- 兄のゼイキンは歌唱力と音楽的センスを持つ
- 兄弟で『YouTubeテーマミュージック』を制作でき、成功条件が揃うと約1億再生へ到達する
- 地方の六人組・東大オンエアでは、リーダーのテツが仲間と地域を守る
- 身体企画の六人組・漁師たちでは、リーダーのシル子が子供人気と安全を両立させる
- 天才YouTuberマコトが台頭し、後の問題につながる危険な兆候が見える

### 第4章「人気という怪物」

成功の影を扱う章。マコトが女性への暴行で逮捕され、過去に兆候を見たヒカキンが何をしたか、逮捕後に誰へ配慮し何を説明するかが問われる。

この事件は話題性のために被害を利用せず、次の基準を守る。

- 暴行を天才の代償や武勇伝として描かない
- 被害者へ責任を転嫁しない
- マコト救済より、被害への配慮と加害を止める責任を優先する
- ヒカキンが加害を黙認、利用した場合は、後の信用へ明確な代償を残す
- 柴田の「マコトを救いたい」は炎上便乗として扱い、正当な救済と混同しない

同時に、過去動画、企業案件、事故、スタッフの労働、兄弟の権利、疲労、古参視聴者との距離など、過去の選択から個人的な危機が変わる。短期の再生数を失っても、説明、補償、休養、改善を選べば最終章までに信用を回復できる。

### 第5章「何者になったのか」

これまで積み上げた能力、活動方針、信用、人間関係、代表動画、過去の約束を最後の一本へ集約する。最終企画は、日本一を取りに行く総合企画、原点と人生を音でつなぐ作品、他人を主役にするプロデュース、炎上を利用する暴露などへ分岐する。

はじめ課長との競争は、最高ルートでは相手を破壊する勝負ではなく、互いを止めない親友同士の競争として決着する。テツとシル子の伏線も成立すると「四皇時代」へ進む。

ダークまっすおは本筋を奪わない。最終表示時に登録者1,800万人以上なら、再生数約5,000回まで落ちたまっすおが笑顔だけの人物像を捨て、「ダークまっすお」として再注目される短いエピローグが加わる。これはエンディング判定を変えない。

## 6. 分岐と周回の仕組み

### 表示する数値

- 登録者数
- 所持金
- 体力
- 表現力
- 制作力
- ビートボックス
- 信用

### 内部で管理するもの

- 原点、炎上傾向、完璧主義、疲労蓄積、野心
- 職人、王道、戦略、交流、炎上、安定の活動方向
- 主要人物とスーパー、制作チームとの関係
- 過去の重要選択を示すフラグ
- その周に選ばれた2種類の時代トレンド

### 一つの選択が返る段階

1. 選択直後の結果文章と数値差分
2. 同じ章の次の場面または追加場面
3. 章末の状態と次章の開始条件
4. 数章後の回想、批判、恩返し、危機
5. 最終企画、エンディング本文、四皇・ダークまっすお差分

各章・各スロットには条件なしのフォールバックがあり、特定ルートへ入れなくても進行不能にならない。固定された節目と、最高priority帯からの条件分岐を併用する。周回記録には閲覧イベント、解放エンディング、発見動画、最高登録者、四皇到達を保存する。二周目以降は30件の周回場面から数件が低確率で本編の間へ挿入され、未閲覧場面を優先する。これは追加場面であり、同じスロットの本編を飛ばさない。

## 7. 5エンディングの判定

エンディングはpriorityの高い順に判定し、最初に条件を満たしたものへ入る。結末は次の5種類から増減させない。

| 優先 | ID | 表示名 | 種別 | 中心条件と意味 |
|---:|---|---|---|---|
| 500 | `controversy_king` | 炎上王 | BAD | 炎上ごとに約50万人が離脱し、第5章で登録者約400万人の炎上の運命が確定する |
| 400 | `number_one` | 日本一のYouTuber | HAPPY | 第5章で日本一を達成。登録者カウンターは約2,000万人へ確定する |
| 300 | `legendary_video` | 伝説の一本 | HAPPY | 第5章で人生作品を完成させ、数字以外の形で時代に残る |
| 200 | `mastermind` | 裏方の天才 | NORMAL | 第5章で出演者から制作者へ軸足を移し、他人を成功させる道を確定する |
| 0 | `street_beatboxer` | 路上のビートボクサー | BAD | 他の結末へ届かなかった場合の最終フォールバック |

能力値と方向性は、第5章で各「運命確定フラグ」を獲得できるかどうかの条件として使う。確定後のエンディング表示はそのフラグを正本にする。これにより、最終場面では炎上王や日本一まで進んだのに、境界値一つで別の結末が表示される矛盾を防ぐ。

### 日本一の最高差分「四皇時代」

次をすべて満たすと、日本一エンドへ「四皇時代」のタイトルと本文が追加される。

- 日本一のYouTuberエンドへ到達
- 第5章で四皇の準備フラグを成立
- はじめ課長との関係55以上
- テツとの関係45以上
- シル子との関係45以上

この場合、ヒカキンは登録者約2,000万人で日本一、はじめ課長は日本二位、テツとシル子はそれぞれ別の価値で時代を作り、四人がYouTuber四皇と呼ばれる。四皇到達は周回記録にも保存する。

### 「伝説の一本」の確定内容

作品名は『音が止まるまで』。社員寮の浴室、初代の安いマイク、ゲームBGM、スーパーのレジ音、笑い声、『YouTubeテーマミュージック』、炎上後の無音までを音でつなぐ。最大再生数ではなく、動画表現でしか残せない一人の人生として、後の作り手へ影響する結末である。

### バッドエンドの役割分離

- 路上のビートボクサー: 活動基盤を失い、スーパーの社員寮へ戻り、夜の路上で唯一の特技を続ける。冒頭の希望を反転させる
- 炎上王: 一時的な再生数は大きいまま、炎上のたび約50万人が登録解除する。嘘、捏造、便乗によって仲間、スポンサー、信用を失い、約400万人まで縮小した数字だけの王になる

### 初見相当の分布基準

ランダムに選択する自動プレイを「正解を知らない初見」の近似として使う。目標は日本一5〜8%、伝説22〜27%、裏方20〜25%、炎上王25〜30%、路上12〜18%。これはゲーム内に固定確率を置く意味ではなく、各ルートの条件と最終選択の誘惑を調整するための回帰基準である。最終調整後の5,000周検証は、日本一5.7%、伝説27.0%、裏方24.5%、炎上王26.9%、路上15.9%となった。

## 9. 自動検証の観点

### 構造検証

`validateContent` とテストで次を確認する。

- イベントIDと同一イベント内の選択肢IDが重複していない
- 全イベントに本文、背景キー、2個以上の選択肢がある
- 追加場面の遷移先IDが実在する
- 5章×12スロットすべてに候補があり、必ず条件なしフォールバックがある
- 指定した5エンディングがすべて存在し、余分な6番目がない
- 最終フォールバックエンディングがある
- 条件で参照するフラグに生成元があるかを警告する

### 物語の時系列検証

`validateNarrativeContinuity` とテストで次を確認する。

- ダンケ、はじめ課長、サックスむらい、マコト、柴田、テツ、シル子を第1章の無名時代へ直接登場させない
- ダークまっすおを第1〜2章へ出さない
- 後の章で初めて作られるフラグを、前の章の必須条件にしない
- 他の投稿者だけの物語にならず、ヒカキンの選択へ戻る
- マコト事件の被害者配慮と、柴田の便乗の位置づけを崩さない

### エンジン検証

- 同じseedでは同じ2種類の時代トレンドになる
- 数値効果、上下限、フラグ、人間関係、代表動画が正しく反映される
- 高priorityイベントと、周回時の未閲覧優先が正しく働く
- 追加場面が基本スロットを余分に消費しない
- 周回限定場面が初回には出ず、二周目以降も同じスロットの本編を飛ばさない
- 最終スロットの追加場面を読み終える前に章が終わらない
- 章移行時に体力と疲労が回復し、次章slot 0へ移る

### 全周回シミュレーション

- ランダム、日本一、職人、裏方、炎上、破綻の6方針で最後まで進行する
- 複数seedで進行不能、無限ループ、エンディング未定義が起きない
- 5種類すべての結末へ実際に到達できる
- 日本一達成フラグが立った日本一志向の周は、日本一エンドで完結する
- 第5章で確定した4種類の運命フラグと、最終表示するエンディングが一致する
- 600周の分布、登録者の最小・最大、場面数、到達率を `npm run balance:report` で再確認する

### UI・保存検証

- タイトルからプロローグ、第1章、最初の選択まで進める
- 選択直後に結果と数値差分を表示し、現在プレイを保存する
- 章の最終選択直後に再読み込みしても、次章導入へ復帰する
- 第5章の最終選択直後に再読み込みしても、エンディングへ復帰する
- エンディング後に周回数、閲覧イベント、代表動画、最高登録者、四皇到達を保存する
- 素材が欠けてもエラーにせず、プレースホルダーのまま操作できる

### 完成時の実行コマンド

```bash
npm run check
npm run balance:report
npm run assets:manifest
npm run build
```

自動検証後、PCブラウザでタイトル、選択、結果、プロフィール、保存再開、章移行、エンディング、周回記録を目視する。画像差し替え後は、全イベントのロジックではなく、代表的な各画面幅で画像の重なりと可読性を追加確認する。
