# 次回の壁打ち — 画像・動画制作

## 再開地点

全5章のシナリオ、分岐、数値、5エンディング、周回要素、PCブラウザアプリは実装済み。画像や動画が一枚もなくても、プレースホルダーで最初から最後まで遊べる。

次回はゲーム設計へ戻らず、まず作品全体の画風とヒカキンのキャラクターデザインを壁打ちする。その後、こちらで相談して決めた設定画を基準に、ユーザーと画像生成を使って素材を一つずつ制作し、実機画面へ差し込んで確認する。

## 次回の最初の問い

最初に決めるのは「このゲームを一目見たとき、どんな作品だと感じてほしいか」。次の項目を言葉と参考イメージで詰める。

1. 写実、アニメ、漫画、シネマティックイラストのどこへ寄せるか
2. 明るいYouTube文化と、後半の重い選択を同じ画風でどう両立するか
3. 2008年の貧しい社員寮と、最終章の巨大スタジオをどんな色の変化で見せるか
4. 若いヒカキンを、実在人物の似顔絵ではない独自キャラクターとしてどう設計するか
5. PC画面上で、文章と選択肢を邪魔せず印象に残る構図をどう統一するか

この5点が決まるまでは全素材の量産へ入らない。最初に少数の試作をゲームへ入れ、画面上で成立することを確認してから横展開する。

## 次回セッションの進め方

### 1. ビジュアル方針を1枚にまとめる

以下を「画風ルール」として確定する。

- 線の硬さ、塗り、陰影、質感
- 基本の色、章ごとの色、炎上場面の色
- カメラ位置、人物の画面占有率、余白の取り方
- 立ち絵とイベントCGで頭身を変えるか
- 背景の情報量と、UI文字を置くための暗部
- 年齢変化の表現方法
- 禁止事項。実在人物への過度な類似、既存ロゴの再現、読める商標、生成画像内の崩れた文字など

決定後、画像生成へ毎回渡す共通プロンプトとネガティブ条件を作る。

### 2. ヒカキンの設定画を作る

最優先は主人公。次の年代を同一人物として認識できる設定にする。

- 18〜21歳: 上京、スーパー、社員寮、安いマイク
- 20代前半: 最初のバズと総合YouTuberへの拡張
- 20代後半: 大型企画、音楽、企業、仲間
- 30代: 頂点争い、信用危機、最終企画
- バッドエンド後: スーパーへ戻った年長の姿

髪型や衣服だけでなく、目つき、姿勢、撮影時の手癖、初代マイクなど、年代を越えて残る識別要素を決める。実在人物の顔を参照するのではなく、本作固有の青年として正面・横・表情差分を作る。

同じ年代ごとに、カメラOFFの小さな姿勢・人見知りの表情と、録画ランプが点いた後の大きな表情を対で作る。最高エンド用には、大歓声の配信中ではなく、配信終了後に初代マイクを持って静かに笑う差分を必須とする。

### 3. 脇役の優先順位を決める

主人公を作った後、物語上の重要度順に設定画を作る。

1. はじめ課長、ゼイキン
2. テツ、シル子
3. マコト、柴田
4. まっすお、ダンケ、サックスむらい
5. 制作チーム、スーパー関係者、群衆

東大オンエアはテツ、としみち、丸眼鏡、`yo!!`、柴竜、ユメマール、漁師たちはシル子、ウダホ、masa、ザ顔、ダーマン、もとけで人物設定が確定済み。グループCGでは六人全員を描くが、個別の大きな立ち絵はテツとシル子を優先し、ヒカキンより素材量を増やさない。

### 4. 最小試作セットをゲームへ入れる

最初の完成確認は、次の少数素材で行う。

- `public/assets/ui/title_hero.webp`
- 第1章冒頭の雪の列車背景
- 18歳ヒカキンの「決意」立ち絵
- 所持金2万円の封筒を見せる冒頭イベントCG
- 少年時代のスキージャンプ台と、二十年後にゼイキンと戻る雪山
- 社員寮の浴室背景
- ゲームBGM動画が伸びるカウンターのイベントCG
- 日本一エンドの背景、立ち絵、イベントCG

試作を入れたら、1920×1080前後のPC画面で次を確認する。

- 顔と重要物がUIに隠れない
- 文字の可読性が落ちない
- 立ち絵と背景の遠近、光源、輪郭が合う
- プレースホルダーから素材へ切り替わってもレイアウトが動かない
- 第1章とエンディングが同じ人物の人生に見える

### 5. 優先度順に量産する

全232イベントへ別々の絵を作る必要はない。共有できる背景と立ち絵を先に作り、物語を象徴する場面だけイベントCGにする。

優先度A:

- タイトル
- 各章の代表背景
- 年代別ヒカキンと基本表情
- 『スーパーマッチ棒ブラザーズ』動画の発見、制作、急上昇
- 『YouTubeテーマミュージック』制作と1億再生
- マコト逮捕後の説明、信用危機
- 最終企画
- 5エンディングと四皇時代

優先度B:

- はじめ課長、ゼイキン、テツ、シル子の主要場面
- スーパー、社員寮、編集部屋、音楽スタジオ、大型企画会場
- ダンケ、まっすお、サックスむらい、柴田の代表場面
- 章をまたいで回収される初代マイク、拒否メール、浴室、古いコメント

優先度C:

- 条件の狭い分岐CG
- 周回希少イベント
- 小物、サムネイル、画面内ポスター
- ループ映像の追加差分

## 動画の作り方

長いムービーではなく、物語画面の背景として数秒で自然に繰り返せる無音ループを基本にする。

- 再生数カウンター、通知、世界地図の光
- 編集タイムライン、波形、録音ランプ
- ステージ照明、観客の光、紙吹雪
- 雨、雪、朝焼け、街の信号
- 炎上コメントの流れ。ただし読める中傷文は作らない

音声はゲーム本体にまだ実装していない。BGM、効果音、ビートボックス、楽曲を追加する場合は、映像制作と分けて音量設計、ミュート、権利確認を行う。

## 素材を作るたびの手順

1. `npm run assets:manifest` で最新パスを確認
2. 対象イベントの本文、年代、場所、表情、分岐上の役割を読む
3. 既存の設定画を参照して生成プロンプトを作る
4. まず1案を生成し、構図、人物の一貫性、権利面を確認
5. 必要な修正だけを明示して再生成
6. WebPまたはMP4/WebMへ整え、マニフェストどおりの場所へ配置
7. `npm run dev` で実際の場面を開き、UI込みで確認
8. 採用理由とキャラクター設定の追加事項を制作メモへ残す

画像生成では、一度に大量の人物を確定しない。主人公の基準画、年代差分、主要人物の順に正本を積み上げる。

## 次回まで固定する正史

ビジュアル制作中も、次の内容は変更しない。

- 主人公は第三者視点で育成する「ヒカキン」
- 開始時の感情は「絶対に何者かになってやる」
- 1989年4月生まれ、2008年3月に高校卒業・上京
- 所持金2万円、東京のスーパー、社員寮、安いマイク
- 海外ビートボクサーを見るためYouTubeを使い、自分も投稿し始める
- 月1〜2本、浴室または自室で何度も撮り直す
- パートナー申請を一度断られる
- 人偏堂『スーパーマッチ棒ブラザーズ』BGMのビートボックス動画が大ヒットする
- ゼイキンとの『YouTubeテーマミュージック』は成功時に約1億再生
- 最高エンドは登録者約2,000万人と、条件付きの四皇時代
- ダンケとまっすおは固定三人組ではなく、各自が一人で活動する友人
- ダークまっすおは最終盤の短いエピローグ
- マコトの暴行事件は被害を軽視せず、加害を正当化しない
- 結末は5種類

実装上の正史と条件は [整合性監査](consistency-audit.md)、章構成は [全5章の分岐設計図](branch-map.md) を参照する。

## 画像制作と並行して決める未確定事項

- 公開時の正式タイトルを「BEAT TO THE TOP」のままにするか
- 東大オンエアと漁師たちのグループCG用ポーズ、表情、衣装の細部
- 全人物の独自デザインと口調の細部
- ロゴ、サムネイル、架空サービス画面のデザイン
- BGM、効果音、ビートボックス、楽曲を実装するか
- 一般公開前にどこまで名称と経歴を独自化するか
- クレジット、利用素材のライセンス、公開・収益化の形

## 画像・動画段階の完了条件

- タイトルから5エンディングまで、主要場面に採用素材が表示される
- 年代をまたいでもヒカキンと主要人物が同じキャラクターに見える
- 背景、立ち絵、CG、ループ映像の色と構図に統一感がある
- 画像内に既存ロゴ、読めない文字、余分な指、不自然な機材などの破綻がない
- すべての素材がマニフェストと一致し、欠落が意図したプレースホルダーだけになっている
- `npm run check` と `npm run build` が成功する
- PCブラウザで最低1周し、画像の重なり、読字性、読み込み時間を確認する
- 公開する場合は、名称、外見、経歴、商標、音楽、肖像・パブリシティー等の確認を終える
