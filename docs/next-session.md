# 次回の壁打ち

## 最初に決めること

次回は、ゲームで管理するパラメーターを5〜7個に絞る。

候補:

- 登録者数
- 所持金
- 体力
- 動画能力
- 信用
- 原点
- 注目度または炎上度

以下を一つずつ決める。

1. プレイヤーへ常に表示する数値
2. 内部だけで管理する性格・ルート用フラグ
3. 各数値を増減させる選択
4. 数値が動画結果やイベント出現へ与える影響
5. 5つのエンディングに必要な条件

## その次に行うこと

パラメーター確定後、第1章の冒頭からYouTubeパートナーのオファーまでを、実際の文章、選択肢、結果込みで作る。

想定する第1章の主要場面:

1. 所持金2万円で東京へ上京
2. スーパーと社員寮での生活開始
3. 安いマイクで最初の撮影
4. 浴室と自室の撮影場所選び
5. 完璧主義と投稿頻度の葛藤
6. 最初の動画投稿
7. YouTubeパートナー申請の拒否
8. 海外動画の研究
9. 『スーパーマッチ棒ブラザーズ』BGM再現動画の制作
10. 24時間20万、1週間100万アクセス
11. 国内月間アクセス1位
12. YouTube側からパートナーのオファー
