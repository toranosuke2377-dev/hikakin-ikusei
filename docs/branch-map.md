# 全5章の分岐設計図

## 変わらない主人公の核

ヒカキンはゲーム開始時から「絶対に何者かになってやる」という野心を持つ。YouTubeを仕事にする発想はまだないが、何者でもないまま終わるつもりはない。

選択によって変わるのは、野心の有無ではなく、何者を目指してどんな手段を使うかである。

- 技術を磨いて認められる
- 幅広い動画で国民的人気者になる
- 流行と数字を分析して勝つ
- 人との縁から大きな企画を作る
- 炎上してでも注目を奪う
- 自分より他人の魅力を引き出す
- 生活を守りながら機会を待つ

## 物語全体

```text
第1章 無名のビートボクサー
  最初の生活・投稿・バズり方が変わる
        ↓
第2章 一千万回の向こう側
  一発屋を脱するための活動方針が変わる
        ↓
第3章 YouTuber新時代
  制作体制、音楽、企業、仲間との関係が変わる
        ↓
第4章 人気という怪物
  過去の選択に応じた危機と逮捕事件への対応が変わる
        ↓
第5章 何者になったのか
  最後の一本と5種類の人生へ収束する
```

## 第1章「無名のビートボクサー」

### 固定される節目

- 2008年3月、所持金2万円で新潟から上京
- 東京のスーパーへ就職し社員寮へ入る
- 安い機材で月1〜2本の投稿を始める
- YouTubeパートナー申請を一度拒否される
- 人偏堂『スーパーマッチ棒ブラザーズ』BGMのビートボックス動画を制作
- 動画が大きく拡散され、YouTube側からパートナーのオファーが届く

### 分岐するもの

- 二万円を機材、生活、活動のどれへ使うか
- スーパーで信頼、体力、人間関係のどれを優先するか
- 浴室、自室、屋外のどこで録音するか
- 完璧を求めるか、投稿頻度を求めるか
- 申請拒否を技術、仕組み、反骨心のどれへ変換するか
- ゲーム音楽の着想を研究、子供、海外、視聴者、偶然のどこから得るか
- 技術型、海外型、コメディ型、ゲームファン型、論争型、遅咲き型のどの形で拡散されるか

最大成功時は24時間約20万、1週間約100万、国内月間アクセス1位、長期約1,000万再生となる。

## 第2章「一千万回の向こう側」

### 固定される節目

- 次回作へ異常な期待が集まる
- 「ゲーム音楽の人」「一発屋」として見られる
- 初めて動画収益を得る
- スーパーを続けるか辞めるか考える
- 活動ジャンルを広げる
- 後発のはじめ課長と接点を持つ

### 分岐するもの

- 最初のバズり方に応じた期待へどう応えるか
- ビートボックス、商品紹介、ゲーム実況、料理、検証、雑談のどれを伸ばすか
- 『パズトラ』実況で人気のサックスむらいから何を学ぶか
- 少し伸び始めたダンケと出会い、友人または仕事仲間になるか
- 幼なじみのまっすおへ知名度、撮影技術、友人関係のどれを与えるか
- スーパーを早期退職、継続、昇進のどれにするか
- 自分を「親分」と慕うはじめ課長を後輩、親友、競争相手のどれとして見るか

まっすお、ダンケ、ヒカキンは固定グループではない。各自が一人で企画・撮影・編集・投稿し、ときどき遊び、相談し、コラボする。

## 第3章「YouTuber新時代」

### 固定される節目

- はじめ課長が大型企画で急成長する
- 企業案件と動画規模が拡大する
- 一人で全制作を続ける限界が来る
- ゼイキンから兄弟での音楽制作を提案される
- 東大オンエアまたは漁師たちと大型企画を行う機会が訪れる
- 天才YouTuberマコトが台頭する

### 分岐するもの

- 一人制作、編集者、友人との協力、企業主導のどの体制を作るか
- ゼイキンの音楽性、ヒカキンの動画感覚、流行のどれを優先するか
- 『YouTubeテーマミュージック』を完成させ、条件次第で約1億再生へ届かせられるか
- 東大オンエアのテツが地元と六人を守る判断を支えられるか
- 漁師たちのシル子が子供人気と安全性を両立する判断を支えられるか
- マコトの危険な兆候へ注意、黙認、利用、距離のどれで応じるか

## 第4章「人気という怪物」

### 固定される節目

- はじめ課長が日本一候補としてヒカキンへ迫る
- マコトの問題が表面化し、女性への暴行で逮捕される
- 柴田が「マコトを救いたい」を投稿する
- ヒカキンの過去の関係と対応が問われる
- 再生数と信用のどちらを守るか迫られる

### 過去から変化する個人的危機

- 過去動画の不適切部分
- 商品紹介のやらせ疑惑
- 身体企画での事故
- 制作スタッフの労働環境
- 企業案件の説明不足
- 長期疲労による活動中断
- ゼイキンとの権利・収益問題
- 古参視聴者からの「変わってしまった」という批判

### 分岐するもの

- マコトへ過去どこまで注意していたか
- 逮捕後に何を説明し、誰へ配慮するか
- 柴田の便乗動画を拒否、討論、利用、無視のどれにするか
- はじめ課長と支え合い、正面対決、企画競争、敵対のどれへ進むか
- 短期的な数字を失ってでも、説明、補償、休養、制作改善を行うか

炎上方向へ進んでいても、この章の途中までは大きな代償と引き換えに信用を回復できる。

## 第5章「何者になったのか」

### 開始状態

- 日本一争いの本命
- 信用を回復している挑戦者
- 登録者競争から離れた職人
- 他人の作品を成功させる制作者
- 高知名度・低信用の炎上系
- 資金と活動基盤を失った元人気者

### 最終企画候補

- 史上最大の大型企画
- 世界規模のゲーム・ビートボックス動画
- ゼイキンとの音楽
- はじめ課長との直接対決
- テツ、シル子との大型コラボ
- 一人で作る原点回帰動画
- 他人を主役にするプロデュース動画
- 信用を取り戻すための一本
- 柴田との便乗・暴露企画
- 捏造された最後の炎上企画
- ヒカキンの人生を集約する「伝説の一本」

### 結末

1. 日本一のYouTuber
2. 伝説の一本
3. 裏方の天才
4. 路上のビートボクサー
5. 炎上王

日本一に加えて、はじめ課長との友情、テツの地域ルート、シル子の安全・子供人気ルートが成立すると、最高版「四皇時代」になる。ヒカキン約2,000万人、はじめ課長日本二位、テツ、シル子の四人がYouTuber四皇と呼ばれる。

## 選択の返し方

一つの選択は最大五段階で影響する。

1. 直後の文章と数値
2. 次に出るイベント
3. 章末の状態
4. 数章後の回想・告発・恩返し
5. エンディング本文と登場人物

序盤に浴室撮影の騒音を謝罪したか、申請拒否をどう受け止めたか、スーパーの人々へどう接したかといった小さな選択も、成功後の場面で別の意味を持って返る。
