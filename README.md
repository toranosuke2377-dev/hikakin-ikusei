# ヒカキン育成ゲーム（仮）

無名のビートボクサー「ヒカキン」を育成し、日本一のYouTuberを目指すPCブラウザ向け選択式育成アドベンチャーです。

1プレイは約1時間。プレイヤーは第三者の立場から人生の節目で選択し、動画の成果、能力、信用、人間関係と物語を変化させます。プレイごとに一部の出来事や流行が変わり、複数のエンディングへ分岐します。

現在は企画・壁打ち段階です。実装や画像制作より先に、ゲーム全体、システム、シナリオ、登場人物、画面設計の順で仕様を固めます。

## 重要な注意

本作はフィクションとして企画しており、実在の人物・団体とは関係がない旨を作中に明記する方針です。一方、現状の名称や経歴には実在の人物・団体を強く連想させる要素があります。一般公開・配布・収益化の前に、名称、人物造形、経歴、商標、肖像・パブリシティーその他の権利について確認し、必要に応じて十分な改変を行います。
